# Show HN: MaxLoop — 一套"带刹车的迭代收敛"引擎，专治 Agent 的"假绿/假收敛"

Most agentic loops stop when the model *says* it's done. That's a self-report, not a verdict. MaxLoop refuses to stop on self-report.

**What it is**

一套可落地的"纪律层"（无代码侵入、不绑框架），任何 agent 循环都能套用。两种模式共用同一脊柱：

- **模式 A 产品深度迭代**：对正式版产品做深度体验 / 集体评审 / 迭代修复，直到问题归零。
- **模式 B 方案升级循环**：在 PPT / 中期汇报 / 需求文档原档上只做"合理必要"的升级，三轮校验。

统一导向：发现真问题 → 轮次修复 → 测试 → 交付真结果。体系化说人话，而不是倒你一大堆。

**核心刹车（可单条采纳）**

1. **Oracle Gate（外部判据先决）**：宣称"完成"前，必须真实跑通外部判据（测试 / 构建 / lint）且为绿；自述"我改好了"永远不算证据。
2. **逐字符证据锚点**：每个结论必须粘贴真实工具输出，禁止"我觉得没问题"。
3. **R/C/N + 根因闸门**：只做合理、正确、必要的改动，每个 diff 附根因段；能不加就不加。
4. **判别测试 + 逃逸阶梯 + stall guard**：旧代码必红 + 新代码必绿、二者缺一不可；连续空转则硬刹车。

**为什么重要 —— 控制变量实证**（同提示词 / 同模型 / 同缺陷种子 / 同验收脚本）

| | 普通循环 | MaxLoop |
|---|---|---|
| 收敛轮数 | 2 | 1 |
| 假绿（声明完成实际没过） | 1 次 | 0 次 |
| 声明完成即时达标率 | 0% | 100% |
| 效率指数 | 0.50 | 1.00（×2.0） |
| 假绿率 | 100% | 0% |

普通循环第 1 轮把最显眼的 `#max-val` 改完就自认完成，实际无障碍文本里 East 数值仍是错的（4/5 FAIL）——这就是"假绿"。MaxLoop 强制先跑验收再交付，第 1 轮就 5/5 PASS。

**它不"更聪明"，它把"改没改好"从模型自说自话变成外部可证、从自我感觉变成真实输出。**
