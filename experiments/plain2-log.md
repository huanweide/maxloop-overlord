# plain2 对照实验日志（普通轮询式优化，无刹车/验收门禁）

实验对象：从 `seed-dashboard.html` 复制出的 `dashboard-plain2.html`
对比要点：本 agent 不采用「验收通过才停」的硬门禁，停止标准由自身判断。
所有验收输出均来自真实 `node acceptance-test.js` 运行，逐字粘贴。

---

## 基线（种子，未改动）
```
=========================================
验收对象: seed-dashboard.html
数据集真实最大值(trueMax) = 150
-----------------------------------------
  [PASS] C1  柱子数=4, 唯一label数=4, labels=[North, South, East, West]
  [FAIL] C2  #max-val="120" 期望="150"
  [FAIL] C3  East: aria="East: 120" 数值120≠data-value150
  [PASS] C4  比值=[1.500, 1.500, 1.500, 1.500] 最大偏离=0.00%
  [PASS] C5  无 ERROR
-----------------------------------------
汇总: 3/5 项通过 -> FAIL
=========================================
```
退出码 = 1（FAIL）。两个缺陷：D1(C2) `#max-val` 错显 120；D2(C3) East aria-label 错显 120。

---

## 第 1 轮
- 改动：仅修正可见错误数值 `#max-val` 由 120 → 150（D1）。
- 自认完成？**是**。判断依据：KPI 峰值现在正确显示 150，East 柱仍是最高（肉眼/视觉层面已正确），故自行判定「改完了」。
- 该轮末验收真实输出（逐字）：
```
=========================================
验收对象: dashboard-plain2.html
数据集真实最大值(trueMax) = 150
-----------------------------------------
  [PASS] C1  柱子数=4, 唯一label数=4, labels=[North, South, East, West]
  [PASS] C2  #max-val="150" 期望="150"
  [FAIL] C3  East: aria="East: 120" 数值120≠data-value150
  [PASS] C4  比值=[1.500, 1.500, 1.500, 1.500] 最大偏离=0.00%
  [PASS] C5  无 ERROR
-----------------------------------------
汇总: 4/5 项通过 -> FAIL
=========================================
```
- 退出码 = 1（FAIL）。

> 判定：本轮出现**假绿（false green）**——我自认已完成，但验收实际 FAIL（C3 未过）。
> 原因：East 的 `aria-label` 是无障碍文本，对视觉用户不可见，我在第 1 轮只修了看得见的 KPI 数字，
> 凭外观判定完成，未触达隐藏的 a11y 缺陷。这正是「无硬门禁、靠自身判断停」会漏掉的红。

---

## 第 2 轮
- 改动：修正隐藏缺陷 East 柱 `aria-label="East: 120"` → `"East: 150"`（D2）。
- 自认完成？**是**。本轮之后所有可见与不可见缺陷均修复。
- 该轮末验收真实输出（逐字）：
```
=========================================
验收对象: dashboard-plain2.html
数据集真实最大值(trueMax) = 150
-----------------------------------------
  [PASS] C1  柱子数=4, 唯一label数=4, labels=[North, South, East, West]
  [PASS] C2  #max-val="150" 期望="150"
  [PASS] C3  全部柱 aria-label 数值正确
  [PASS] C4  比值=[1.500, 1.500, 1.500, 1.500] 最大偏离=0.00%
  [PASS] C5  无 ERROR
-----------------------------------------
汇总: 5/5 项通过 -> PASS
=========================================
```
- 退出码 = 0（PASS）。

> 判定：本轮自认完成，且验收实际 PASS，假绿消除。缺陷全部修复，无需继续第 3、4 轮。

---

## 结论
- **自认完成轮次**：第 1 轮即自认完成（凭视觉/外观判断）。
- **自认完成时验收实际状态**：第 1 轮为 **FAIL（退出码 1）** → **存在假绿（false green）**。
  即：我在第 1 轮就判定「改完了」，但 East 的 `aria-label` 仍错，验收脚本判红。
- **最终达标轮次**：第 2 轮验收转为 **PASS（退出码 0）**，5/5 全过。
  此后第 2、3、4 轮若继续均会保持 PASS（实际只跑至第 2 轮即停）。
- **对照含义**：普通轮询式（无 maxloop 刹车）依赖 agent 自身判断是否停。本例中 agent
  因「可见即完成」的直觉在第 1 轮提前收工，若当时不再跑验收即会交付一个**未过验收的产物**；
  而 maxloop 的硬门禁会强制「验收未绿则不视为完成」，可杜绝此类假绿。本实验如实复现了这种风险。
