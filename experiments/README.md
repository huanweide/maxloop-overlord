# experiments/ · 控制变量实证

本目录存放 MaxLoop 的**控制变量**对照实验：用**同一提示词**、**控制变量**，测 MaxLoop 对某项任务的**工程提升幅度**。所有数字来自真实运行，逐字符可追。

## 实验协议（固定）

| 项 | 设定 |
|---|---|
| **同提示词** | 两组使用**逐字相同**的任务提示词 |
| **控制变量** | 仅「是否启用 MaxLoop 方法论」不同；模型、起始材料、轮数预算完全相同 |
| **对照组** | A：普通迭代（模型自述"完成"即止，无外部判据） |
| **实验组** | B：MaxLoop（Oracle Gate + 判别测试 + 证据锚点 + R/C/N + 逃逸阶梯） |
| **任务范围** | 针对某个具体产物（如一个 HTML 可视化 / 一段代码 / 一份方案原档） |
| **观测指标** | 真实达标率、是否落入"假绿"（声称完成实则未过）、收敛轮数、效率指数 = 级别 ÷ 轮数 |
| **证据要求** | 每个"提升 X"结论必须附判别测试输出与逐字符锚点，否则不出报告 |

## 运行方式

由 agent 按 `../SKILL.md` 的 Chair 清单执行，原始记录（每轮输出、判别测试、台账）随结果一并落盘。

## 结果文件

- `controlled-study-YYYYMMDD.md`：单次实验原始记录与结论
- 真实数值将回填 `../efficiency-dashboard.html` 替代示意基线
